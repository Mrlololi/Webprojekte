Layout and scroll animation demo

KittyCats

Kittens grow up, and not always into what you expected. Scroll down to meet them. Each section on the way shows one way to build a responsive layout and one way to animate it, with HTML, CSS and a little GSAP.

Meet the kittens

Technique Fluid layout. clamp() scales text and spacing with the screen, and aspect-ratio keeps space free for the drawing, so nothing jumps while the page loads.

Animation GSAP timeline. The kitten blinks and both cats flick their tails for about four seconds, then rest. ScrollTrigger replays the scene when this part comes back into view and pauses it when it leaves. Eyes and tail follow two custom properties, --blink and --tail, which pass through <use>, so one SVG symbol can blink in many places. The kitten on the bottom edge walks with your scroll position: CSS animation-timeline: scroll(), or ScrollTrigger with scrub in browsers without scroll timelines.

01. Sticky section

A few honest questions

Keep scrolling. The heading stays where it is, the cards pile up on top of each other, and the cat's mood changes with every question.

Technique position: sticky. The heading sticks inside its column. Each card sticks a bit lower than the one before, so they stack like a deck of cards.

Animation SVG path morph, no paid plugin. The tail, eyelids and mouth have the same path commands in both moods, so GSAP tweens the numbers inside the d attribute (attr: { d }), plus the pupils' rx and the tail's stroke-width. ScrollTrigger with scrub ties the mood to your scroll position through the three cards.

02. Grid gallery

From kitten to cat

Point at a kitten, tab to it or tap it to see the grown-up version. Tap again to go back.

Technique CSS Grid. On phones, repeat(auto-fit, minmax(9.5rem, 1fr)) fits in as many tiles as there's room for. From 768px it's a four-column grid, and the first tile takes up two rows and two columns.

Animation GSAP ScrollTrigger. ScrollTrigger.batch() lifts the tiles 24px into place in a short stagger and plays it backwards when you scroll back above them, so the entrance replays every time. Each kitten blinks once when its tile arrives.

03. Flexbox card row

More kitties to choose from

Eight cats with eight different characters. Some descriptions are longer on purpose, so you can see the buttons still line up.

Technique Flexbox. The cards wrap with flex-wrap: wrap and keep one width (flex: 0 1 15rem). justify-content: center keeps a short last row in the middle. Inside each card, margin-top: auto pushes the button to the bottom.

Animation CSS scroll-driven animation. Each kitten stretches long and low while its card comes into view, with no JavaScript: animation-timeline: view() and animation-range: entry 0% cover 40% inside @supports. The tail angle is a registered custom property (@property --tail), so it animates too. Browsers without scroll timelines play the same stretch once, started by an IntersectionObserver.

04. Two-column split

About KittyCats

Technique Two-column split. A grid with two columns, minmax(0, 1.15fr) minmax(0, 1fr). Below 768px it becomes one column, and the order in the HTML stays the same.

Animation GSAP ScrollTrigger, scrubbed. From 768px the card on the right drifts 40px against the text, tied to the scroll position (scrub: 0.8, ease none). The checklist slides in and replays on re-entry. On phones gsap.matchMedia() leaves only a fade, and nothing on this page is ever pinned.

05. Form grid

Get more information

Tell us what you like and we'll find the purrfect match. It's a demo, so nothing leaves your browser.

Technique Form grid. Two columns from 768px. Fields that need the full width get grid-column: 1 / -1. The checks are the browser's own, and screen readers hear the error messages too.

Animation None, on purpose. Nothing moves next to the fields, so typing and reading error messages stay calm.
